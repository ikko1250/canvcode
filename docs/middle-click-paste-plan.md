# 中ボタンでパンすると、PRIMARY の選択の文字が貼り付けられる

Ubuntu で開くと、中ボタンでパンして離したときに、前に選んだ文字（クリップボードの中身に見える）が文字のカードとして置かれる。

## 原因

- Linux のブラウザは、中ボタンを離すと、最後にマウスで選んだ文字（X11 / Wayland の PRIMARY の選択）を貼り付ける。
  Ctrl+C のクリップボードとは別で、文字を選んだだけで入る。
- そのとき `paste` イベントが来る。キャンバスは `window` の `paste` を受けて（MAI-26）、文字なら文字のカードにする。
  フォーカスがキャンバスにあれば、編集できる要素でなくても来る（Chromium も Firefox も）。
- 文字やドキュメントを編集している間のパン（編集を続ける）では、その文字の中に貼られる。
- 中ボタンを押したときの `pointerdown` は `preventDefault` していたが、貼り付けは離したときの既定の動作なので止まらない。
  - Chromium：`pointerup`（と `mouseup`）の既定の動作。`pointerup` を `preventDefault` すると止まる。
  - Firefox：`auxclick` の既定の動作。`auxclick` を `preventDefault` すると止まる。
- Windows・macOS には中ボタンの貼り付けがないので起きない。

## 直し方

- キャンバスの中ボタンのパン（とポータルを開くクリック）を終えたときだけ、`pointerup`（Chromium）と `auxclick`（Firefox）を
  `preventDefault` する（`packages/canvas/src/view.ts`）。パン中も続けている文字・ドキュメントの編集に入らない。
  - 編集中の文字の中で押した中ボタンは、文字の要素が `pointerdown` を止めていて、パンにならない。そこではふつうに貼り付ける。
- ページのどこかで中ボタンを離した、そのタスクの間に来た `paste` は、キャンバスに貼らない（`onPaste`）。
  `window` の capture で `pointerup`・`auxclick` を見る。キャンバスの外（上のバー・AI 付箋の札など）で離したものも、
  文字のカードにしない。入力欄などへの貼り付けは、もとからブラウザに任せている（`ownsClipboardEvent`）ので、今のまま。
  - ボタンを 2 つ押していて中ボタンを先に離すと、Chromium では `pointerup` ではなく `pointermove` になるので、それも見る。

## タスク

1. e2e（`tests/e2e/middle-click-paste.spec.ts`）を足す。キャンバスの外の文字をマウスで選んで PRIMARY に入れ、
   - 中ボタンでパンしても、中ボタンでクリックしても、`paste` イベントが来ず、ノードが増えない
   - 文字を編集しながら中ボタンでパンしても、文字が変わらない
   - キャンバスの外で中ボタンを押すと `paste` が来る（確かめる側。PRIMARY に入っている）が、文字のカードにならない
   - 中ボタンでパンしながら左ボタンを押し、中ボタンを先に離しても、文字のカードにならない
   - 編集中の文字の中で中ボタンを押すと、そこに貼り付けられ、パンしない
2. `view.ts` を直す。
3. 直す前のコードで落ち、直したあとは通ることを、Chromium と Firefox で確かめる。止め方がブラウザで違うので、
   この e2e だけ Firefox でも回す（`playwright.config.ts` の `firefox` のプロジェクト）。

## レビューで見つかったこと（直した）

1. 初めは、キャンバスの要素で、中ボタンの `pointerup`・`auxclick` をいつも止めていた。編集中の文字の中での中ボタンの貼り付け
   （Linux のふつうの操作）までできなくなった。パンを終えたときだけ止める。
2. 前からあった：キャンバスの外（上のバー・AI 付箋の送るボタンなど。キャンバスの要素の外）で中ボタンを押すと、
   フォーカスが `body` に移り、`paste` をキャンバスが受けて、文字のカードになる。中ボタンを離した直後の `paste` は貼らない。
3. Chromium で、ボタンを 2 つ押していて中ボタンを先に離すと、文字のカードになる（`pointermove` になる）。2 と同じ所で見る。
4. `playwright.config.ts` は Chromium だけで、Firefox の止め方（`auxclick`）を消してもテストが通る。この e2e だけ Firefox でも回す。
   確かめる側のテストのコメントが違い（「中ボタンを使わない」）、文字のカードができていることを見ていなかった。直した。
