# 三角形と Chromium の E2E

矩形などの図形を選択し、デザインパネルの「形」で上向きの三角形に変更できるようにする。図形の保存形式は既存の `geo` を使う。E2E は Playwright 同梱 Chromium で実行する。

- [x] 図形型とデザインパネルに三角形を追加する。
- [x] 多角形の描画、クリック判定、接続点を再利用し、文字領域を三角形内に収める。
- [x] Playwright、npm スクリプト、README のブラウザ設定をそろえる。
- [x] 形の切り替え、Undo・Redo、再読み込みをテストする。
- [x] 独立レビューを受け、空のワークスペースで確認環境を起動する。

## 頂点を動かして直角三角形にする

- [x] 頂点の位置を上辺に対する割合で保存し、両端で直角になるようにする。既存の三角形は中央を既定とする。
- [x] 単体選択時に黄色い調整ハンドルを一つ表示する。リサイズ用のハンドルとは位置をずらし、横方向のドラッグを Undo 1 回で戻せるようにする。
- [x] 頂点に合わせて文字領域を移し、端まで動かした場合の描画と Undo を E2E に含める。

## 正方形への吸着

- [x] 矩形と三角形を単体でリサイズするとき、表示上の幅と高さの差が 8 px 以内で同じ長さにそろえる。差が 12 px を超えると吸着を解除する。
- [x] 辺では動かさない辺の寸法を使い、角では両軸を同じ量だけ補正する。Shift の縦横比固定、Alt の中心を基準にした操作、Ctrl / Cmd のスナップ解除に対応する。
- [x] 寸法が近づいたときと通り過ぎたとき、通常の Undo をテストする。

## 吸着中の寸法表示

- [x] 正方形への吸着中に、既存の赤い寸法線と数値ラベルで幅と高さを表示する。回転した図形では寸法線を辺に沿わせ、数値は水平に表示する。
- [x] 吸着解除とドラッグ終了時に寸法表示を消す。表示色、回転時の位置、表示の終了をテストする。
