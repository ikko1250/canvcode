# 全画面のエディタの Claude のパネルが右半分からはみ出す（MAI-102 の不具合）

全画面のエディタ（Markdown・Python・表）の右半分に出した Claude のパネルが、会話に長い行があると右半分より広がる。
はみ出した右側は置き場所（`.file-editor-claude`。`overflow: hidden`）で切れ、右寄せの送るボタンが見えなくなる。

## 原因

- 右半分では、パネルの幅を `flex: 1; width: auto` にしている（`.file-editor-claude .claude-panel`）。パネルは置き場所の
  flex の子で、`min-width` が既定の `auto` のままなので、中身の折り返せない一番長い行（min-content）より狭くならない。
- 折り返せない行は、ツールの行（`.claude-tool`。`white-space: nowrap` で 1 行にし、省略記号で切る）と、コードブロック
  （`.claude-text pre`。横にスクロールする）。どちらも、切る・スクロールする前にパネルのほうが広がる。
- キャンバスの右では `width: 380px` と幅が決まっているので、最小の幅も 380px までになり、起きない。
- 測った値（画面の幅 1280px、右半分 640px）：長いツールの行で 1379px、長いコードブロックで 1241px に広がり、送るボタンの
  右端は画面の外（2007px・1869px）。長い URL は `overflow-wrap: anywhere` で折り返すので広がらない。

## 直し方

- `.file-editor-claude .claude-panel` に `min-width: 0` を足す。パネルは右半分の幅に収まり、長いツールの行は省略記号で切れ、
  コードブロックはブロックの中で横にスクロールする。見た目はほかに変えない。

## レビューで見つかった、前からあった見切れ（あわせて直す）

- 置き場所の `.file-editor-claude` の `overflow: hidden` で、右半分が 390px より狭いとき（画面の幅 721〜779px）、
  モデルを選ぶ欄（326px。モデルのボタンの右端に合わせて開く）の左の端が切れる。画面の幅 730px では 25px 切れ、
  「Model ›」の左を押すとエディタに入る。パネルが `min-width: 0` で収まるので、置き場所では切らないようにする
  （キャンバスの右の置き場所も `display: contents` で切らない）。
- `.claude-error`（会話の中のエラーと、入力欄の下の送れなかったときのエラー）に `overflow-wrap: anywhere` がなく、
  区切れない長い語（パスなど）で、会話の欄が横にスクロールし、入力欄の下のものは切れる。Firefox は `/` で折り返すので
  起きない。`overflow-wrap: anywhere` を足す。
