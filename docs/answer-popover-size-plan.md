# AI 付箋の答えのパネル：文字を小さく、高さを大きく、下が詰まっていれば上にずらす

ユーザーの頼み：AI 付箋の回答の枠（付箋の横の答えのパネル、`AnswerPopover.tsx`）の文字を少し小さくし、枠の最大の大きさを大きくする。
下が詰まっているときは、上にずらして枠の大きさをとる。

## 今の作り

- パネルは幅 360px、高さは中身に合わせて 480px（`POPOVER_MAX_HEIGHT`）まで。本文は中でスクロールする。
- 上の端は付箋の上の端に合わせる。ただし `height - 160` より下には置かない。
  高さの上限は「キャンバスの下の端までの残り」（160px より小さくはしない）。
  そのため、付箋が画面の下のほうにあると、パネルは 160px ほどに縮み、上が空いていても使わない。
- 本文は会話と同じ読む文の文字（`.claude-text`：16px・行間 1.7。見出しは 18px、コードは 14px）。

## 直し方

1. 文字（`styles.css`）：パネルの中の本文だけを 14px・行間 1.7（DADS の Std-14N-170）にする。見出し（h1〜h3）は 16px の太字・行間 1.6。
   コードは今の 14px のまま（画面の文字の下限が 14px なので。MAI-112）。
   質問のタブの答え（同じ `AnswerView`）と会話は、今の 16px のまま。
2. 高さの上限（`AnswerPopover.tsx`）：480px から 640px にする。幅は 360px のまま。
   上限は、上下の余白（8px ずつ）を除いたキャンバスの高さを超えない（160px より小さくはしない）。付箋の位置にはよらない。
3. 位置：パネルの実際の高さ（中身に合わせた高さ）を測り、上の端は付箋の上の端に合わせたうえで、
   パネルの下の端がキャンバスの下の端（から 8px）を超えるなら、超えない所まで上にずらす（上の端は 8px より上にしない）。
   - 高さは `useLayoutEffect`（描くたび。描く前に測るので、ずれた位置が一瞬出ない）と `ResizeObserver`（書体の読み込みなど、React の外での変化）で測る。
   - 高さの上限は位置によらないので、測った高さで位置を決めても、高さは変わらない（行ったり来たりしない）。
   - 短い答えなら、ずらさない（付箋の上の端に合わせたまま）。

## タスク

1. `styles.css` に、パネルの中の `.claude-text` の文字を足す。
2. `AnswerPopover.tsx` の高さの上限と位置の決め方を直し、先頭のコメントを直す。
3. e2e（`tests/e2e/canvas-answer.spec.ts`）を足す。
   - 付箋を画面の下のほうに置いて長い答えのパネルを開くと、パネルの下の端がキャンバスの中に収まり、高さが 160px より大きい（上にずれる）。
   - 付箋が上のほうにあれば、パネルの上の端は付箋の上の端に合う。
   - パネルの本文は 14px、質問のタブの答えの本文は 16px のまま（`ui-typography.spec.ts`）。
4. 型チェック・lint・関わる e2e を回す。
