# Claude のパネルを閉じても、書きかけを残す

ユーザーの頼み：作業パネル（Claude のパネル）を閉じたときに、書いていた内容が消えてしまうのは、使い勝手が悪い。

## 今の作り

- パネルは、閉じると描くのをやめる（アンマウント）。描くかは `claudeView !== null && availability === 'on'`（`App.tsx`）で、
  会話（`ClaudePanel`）と作業のタブ（`QuestionPanel`）を、同じ条件で描いている。
- 閉じる操作は、どれも `closeClaude`（`App.tsx`）か、右上の「作業」のボタンに行き着く：会話の ×、会話の入力欄の中と外の Esc、
  作業のタブの × と一覧の Esc、右上の「作業」。
- 閉じると消えるもの（`ClaudePanel` の状態）：入力欄の文、取り込む付箋の質問の札、「会話｜質問」、選んでいる会話（開き直すと、
  30 分以内に動いた最新の会話か、新しい会話を選び直す）、会話の欄のスクロール、開いていた「▸ 読んだ・調べた N件」と「⚙ 動作中の作業」、
  誤りの表示、「全部止める」の 1 回目。
- 閉じても残るもの：📍 添えた場所の札（App が持つ）、モデルと effort（会話ごとに覚える）。
- 作業↔会話のタブ、キャンバスを移る、全画面のエディタ↔キャンバスでは、今も隠すだけで、残る。
- ほかに書きかけが消える所：
  - 会話の入力欄の Esc は、IME の変換中を除いていない（Enter は除いている）。変換をやめるつもりの Esc で、パネルが閉じる。
  - 「グラフを作る」の「Claude におまかせ」は、入力欄を頼み方の下書きで上書きする。

## 直し方

1. 会話のパネル（`ClaudePanel`）は、一度開いたら、閉じても描いたまま `hidden` で隠す。
   - App で「一度開いた」を覚える（`claudeMounted`）。会話のパネルは「一度開いた かつ Claude を使える」の間ずっと描き、閉じている間は隠す。
     初めて開くまでは描かない（開く前はパネルがない、を今のままにする）。
   - 作業のタブ（`QuestionPanel`）は今どおり、閉じたら描くのをやめる（閉じたら一覧に戻る、を変えない）。
   - 「開いているか」を見る所（全画面のエディタの右半分に出すか、など）は、`claudeView` を見る。
   - 閉じたら、誤りの表示と「全部止める」の 1 回目は消す（開き直したときに、前の誤りを出さない）。作業のタブとの行き来では、今どおり残す。
   - 開き直したときに開くタブは今どおり（作業のタブから。MAI-91）。フォーカスとスクロールは、今の仕組み（見せたら入力欄にフォーカスする・
     置き場所が変わったらスクロールを戻す）で戻る。
   - 隠したパネルの中にフォーカスを残さない。× と Esc は、先にエディタかキャンバスへフォーカスを移している。右上の「作業」で閉じたとき、
     押してもボタンにフォーカスが移らないブラウザ（Safari）では入力欄に残るので、隠したときにパネルの中にあれば外す。
   - 書きかけは会話ごとに分けず 1 つで、会話を替えても付いてくる（今のまま）。ページを読み直したときは残さない。
2. 会話の入力欄の Esc で、IME の変換中は閉じない（`isImeEvent` で除く。claude/ のほかの Esc と同じ）。
3. 「Claude におまかせ」は、入力欄が空なら下書きを入れ、書きかけがあれば空行を挟んで後ろに足す。同じ下書きがもう入っていれば足さない
   （閉じても書きかけが残るので、2 回押すと同じ文が 2 つ並ぶのを避ける）。前に入れた下書きのまま手を入れていなければ、置き換える。
   下書きは会話で送る（「質問」を選んでいても「会話」にする。下の「レビューで見つかったこと」）。
4. コメントと README（「閉じても書きかけは残る」）を直す。

## 確かめること

- e2e（`tests/e2e/claude-panel.spec.ts`）：
  - 入力欄の Esc・入力欄の外の Esc・会話の ×・右上の「作業」・作業のタブの Esc と × のそれぞれで閉じ、開き直すと、
    文・取り込む札・「質問」の選択・会話の欄のスクロールが残る。閉じたあと、隠したパネルの中にフォーカスがない。
  - ＋ で新しい会話にして閉じ、開き直しても新しい会話のまま。
  - 送れなかったときの誤りは、閉じて開き直すと消える（文は残る）。送れたあとに閉じて開き直すと、欄は空。
  - 全画面のエディタで Esc で閉じ、表示の「Claude」で開き直すと、書きかけが残る。
  - 「Claude におまかせ」：空なら入れる、書きかけがあれば後ろに足す、同じ下書きは足さない。
  - 閉じたあとの「パネルがない」（`toHaveCount(0)`）は、会話のパネルの分を「隠れている」（`toBeHidden()`）にする（claude-panel と ui-typography）。
- e2e（`tests/e2e/ime.spec.ts`。Chromium だけ）：会話の入力欄で変換中に Esc を送っても、パネルが開いたままで文が残る。
- 足す e2e は、直す前のコードで落ちることを確かめる。関わる e2e（claude-panel・ime・canvas-answer・target-size・ui-typography）、
  型チェック、lint が通ること。

## レビューで見つかったこと

独立したサブエージェントのレビューで、直すべきものが 1 つ見つかった。ほかのものもあわせて直した。

1. 直すべき：「質問」のまま閉じてから「Claude におまかせ」を押すと、グラフの頼みが「質問」（`/api/claude/answer`）で送られ、
   `plot_csv` が使えずグラフが置かれなかった。閉じても「会話｜質問」が残るようにしたので、よく起きるようになった。
   下書きを入れるときは「会話」にする（付箋の質問を取り込むときと同じ）。e2e を足した（「質問」にして閉じ → おまかせ → 「会話」が選ばれ、
   送り先が会話）。直す前は「会話」が選ばれていずに落ちた。
2. 直したほうがよい：閉じても、長い会話を SSE の知らせのたびに描き直して重かった（前は閉じれば描くのをやめていた）。
   隠している間（閉じている間と、作業のタブを見ている間）は、会話の欄（`ChatLog`）を描き直さず、前に描いたものをそのまま出す
   （`ClaudePanel.tsx` の `Frozen`）。見せたら、そのときの中身で描き直す（スクロールの戻しは今どおり）。`ChatLog.tsx` は変えていない。
   300 件の会話で、知らせ 1 つあたりの時間（開発ビルドの Chromium の目安。レビュー役の perf.spec.ts）：

   | パネル | 直す前 | 直したあと |
   | --- | --- | --- |
   | 一度も開いていない | 3.57ms | 3.64ms |
   | 開いて、＋で新しい会話にして閉じた | 2.57ms | 2.54ms |
   | 開いて閉じた | 58.57ms | 2.67ms |
   | 開いて、作業のタブを見ている | 59.23ms | 2.82ms |

3. 隠したときにフォーカスを外す所を守るテストがなかった（Chromium は、あとでフォーカスを直すので、前の e2e は外さなくても通った）。
   `element.click()` で閉じ（押してもフォーカスが移らない Safari と同じ）、同じタスクの中でフォーカスがパネルの外にあることを見る e2e にした。
   外す所を消すと落ちることを確かめた。
4. 「おまかせ」で違う下書きが 2 つ並んだ（表の「おまかせ」を何も直さずに閉じ、グラフの「おまかせ」をしたとき）。前に入れた下書きのまま
   （前後の空白を除いて同じ）なら、置き換える。手を入れた書きかけなら、今どおり後ろに足す。`withDraft` を `claude/promptDraft.ts` に分け、
   単体テストで守る（直す前は、置き換える所が落ちた）。
5. モデルを選ぶ欄・会話の一覧・この会話のメニューを開いたまま閉じると（キーボードで閉じたとき。欄の外を押せば、欄は自分で閉じる）、
   開き直しても開いたままだった。閉じたら閉じる（`closeRequest`）。e2e を足した（直す前は、モデルを選ぶ欄が開いたままで落ちた）。
6. コメント：`ClaudePanel.tsx` の「会話｜質問」のタブ → 「会話｜作業」。`App.tsx` の「Claude を使えなくなると描き直す」は誤り
   （`ClaudeClient` は一度使えるとわかったら、使えないには戻らない）なので、書き直した。
