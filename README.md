# CanvCode

ドキュメント管理機能と階層構造を持つ infinite canvas。設計は Linear の MAI-1（MAI-2〜MAI-16）を参照。

現在は段階 11-2（旧データの取り込み）まで。MAI-2 の導入順はここで一巡した。ほかに、Markdown カードを画像にして描く方法の検証ページ（`?lab=markdown`）がある。キャンバスとノードはサーバーの SQLite に保存され、同じワークスペースを開いたほかのタブ・端末にもすぐ届く。

## 構成

| パス | 内容 |
| -- | -- |
| `packages/core` | 幾何計算・カメラ・fractional index・ID・ストア・Undo（DOM に依存しない） |
| `packages/nodes` | ノードの型（`defineNodeType`、図形・テキスト・付箋・画像・フリーハンド・矢印・Portal・グループ・フレーム・Markdown カード・コードカード・PDF のページ） |
| `packages/canvas` | ワークスペース（ストア・履歴・階層・ゴミ箱）・Canvas ごとの Editor・描画（Canvas2D の 3 レイヤー）・入力・ツール・空間インデックス・矢印のつながり・File の読み書きと編集（CodeMirror） |
| `apps/web` | React の画面（サイドバー・パンくずリスト・右クリックメニュー・全画面のエディタ） |
| `apps/server` | Node のサーバー（127.0.0.1 でのみ待ち受け、ビルドした画面の配信、レコードの保存（SQLite）と WebSocket での同期、画像・PDF・サムネイルの保存、.md の読み書きと変更の監視） |

## 使い方

Node 24 以上が必要。

```bash
npm install
npm run build   # 型チェックと画面のビルド
npm start       # http://127.0.0.1:8787
```

ワークスペースのフォルダは `npm start -- --workspace <フォルダ>` か、環境変数 `CANVCODE_WORKSPACE` で指定する（既定は `./workspace`）。

- Markdown と Python は、ワークスペースのフォルダに普通の `.md` / `.py` ファイルとして置く（サブフォルダも可）。SSH から Neovim などで直接編集してよく、変更はブラウザに届く
- 貼り付けた画像と取り込んだ PDF は `<ワークスペース>/.canvcode/assets/` に、中身の SHA-256 を名前にして保存される。PDF は検索用のテキストも `<ハッシュ>.pages.json` に取り出しておく
- File の id とパスの対応は `.canvcode/files.json`、完全に削除したファイルは `.canvcode/deleted/` に置く
- キャンバス・ノード・矢印のつながり・引用などのレコードは `.canvcode/workspace.db`（SQLite）、Portal のサムネイルは `.canvcode/thumbnails/` に保存される。操作するたびに少し待ってサーバーへ送る。右上に「保存済み」「保存中…」「未接続」が出る。サーバーが止まっている間の変更は、つながったら送る（タブを閉じると失われる）
- Canvas ごとの最後のカメラは、ブラウザ（端末ごと）に覚える
- 旧アプリ（recursive-infinite-canvas）の `.ricbackup` は、画面にドロップするか、VPS の上にあるなら `npm run import -- --workspace <フォルダ> <ファイル>` で取り込む（サーバーが動いていればサーバーに頼み、開いているタブにもすぐ届く）。ワークスペースが空なら旧のルートがそのままホームに、空でなければホームの下の「取り込み（日付）」に入る。ゴミ箱の中のものと AI 会話は取り込まない。元のファイルは `.canvcode/imports/` に残る
- バックアップはワークスペースのフォルダを丸ごとコピーすればよい。サーバーを動かしたままコピーするときは、先に `npm run snapshot -- --workspace <フォルダ>` で `workspace.db` の写し（`.canvcode/snapshots/`）を作る

VPS 上で動かし、手元の PC からは SSH のポートフォワードで開く。

```bash
ssh -L 8787:127.0.0.1:8787 <VPS>
# ブラウザで http://localhost:8787 を開く
```

開発時は `npm run dev`（Vite、http://127.0.0.1:5173）。ポートフォワードは `-L 5173:127.0.0.1:5173`。

```bash
npm test        # ユニットテスト（Vitest）
npm run lint    # oxlint
```

## 操作

| 操作 | 入力 |
| -- | -- |
| パン | ホイール、Space+ドラッグ、中ボタンドラッグ、手のひらツール（H） |
| ズーム | Ctrl（⌘）+ホイール、トラックパッドのピンチ |
| 全体表示 | Shift+1 |
| ツール | V 選択 / H 手のひら / R 矩形 / O 楕円 / T テキスト / N 付箋 / F フレーム / D フリーハンド / E 消しゴム / A 矢印 / P Portal |
| 文字の編集 | ダブルクリック、または選択して Enter。Esc か Ctrl（⌘）+Enter、ほかの場所のクリックで終える |
| 選択 | クリック、Shift+クリックで追加・解除、Ctrl+A で全選択 |
| 範囲選択 | 何もない所からドラッグ（枠に触れたノードを選ぶ。フレームは丸ごと囲んだときだけ）。Shift で追加 |
| グループ | Ctrl+G でまとめる、Ctrl+Shift+G で解除。ダブルクリックで中に入って子を選べる。Esc で外に出る |
| フレーム | F でドラッグして作る（中に丸ごと入ったノードを取り込む）。ノードをフレームの上へドラッグすると中に入り、外へ出すと外れる。中身はフレームの枠で切り抜いて描く |
| 移動 | ドラッグ、矢印キー（Shift で 10） |
| リサイズ | 選択枠の角・辺をドラッグ（Shift で縦横比を保つ、Alt で中心を基準にする） |
| 回転 | 選択枠の上の丸いハンドルをドラッグ（Shift で 15° 刻み） |
| コピー・切り取り・貼り付け | Ctrl+C / Ctrl+X / Ctrl+V。Shift+Ctrl+V でポインタの位置に貼り付け |
| 複製 | Ctrl+D |
| 画像 | 貼り付け、またはファイルをドロップ（PNG・JPEG・GIF・WebP・AVIF・BMP）。リサイズしても縦横比を保つ |
| 文字列の貼り付け | テキストノードになる |
| フリーハンド | D でドラッグして描く。Shift を押している間は直線（押したときの点から）。色と太さは左端のパレットで選ぶ。描いたあともフリーハンドのまま |
| 消しゴム | E でなぞった手書きの線を消す（ほかのノードは消さない）。Esc で取り消し |
| 矢印 | A でドラッグして引く。図形の上で離すと中心へ向かってつながり、少し止まってから離すと指した点につながる。Ctrl（⌘）を押している間はつながない |
| Portal | P でクリック（ドラッグで大きさを決める）すると、新しい子のキャンバスとその Portal ができ、中に入る。ダブルクリックか、選んで Enter で中に入る |
| 階層の移動 | 上端のパンくずリスト、左のサイドバー（Ctrl+\ で開け閉め）、ブラウザの「戻る」「進む」 |
| キャンバスの名前 | Portal を右クリック →「名前を変更」（中に入らずに、その場で変える）。または、サイドバーで今開いているキャンバスか、パンくずリストの右端の名前をダブルクリック |
| Portal の削除 | 持ち主の Portal を消すと、中身ごとゴミ箱に送るか、「未配置」にするかを尋ねる。ゴミ箱と未配置はサイドバーから戻せる |
| Portal のコピーと移動 | コピーして貼るとショートカット（点線の枠）。切り取って別のキャンバスに貼ると、キャンバスごと移る |
| 昇格 | 選んだものを右クリック →「キャンバスに昇格」（Ctrl+Alt+P）。新しいキャンバスに移し、元の場所に Portal を置く |
| 右クリックメニュー | 昇格・複製・グループ・削除。何もない所では「ここに新しいキャンバス」 |
| Markdown | M でクリック（ドラッグで幅を決める）するか、右クリック →「ここに Markdown」で「無題.md」を作って、その場で編集する。表を貼り付けると「貼り付けた表.md」、.md をドロップするとワークスペースに保存してカードを置く |
| Markdown の編集 | ダブルクリックか、選んで Enter でその場で編集（Esc で終える）。Ctrl（⌘）+Enter で全画面（左に本文、右にプレビュー）。本文は少し待ってファイルに保存される |
| Markdown のカード | 高さは中身に合わせる。右クリック →「大きさを固定」（高さを手で変えても固定になる）。リンクは Ctrl（⌘）+クリックで開く。「名前を変更」でファイル名も変わる |
| Python | Y でクリック（ドラッグで幅を決める）するか、右クリック →「ここに Python」で「無題.py」を作って、その場で編集する。.py のドロップも可。カードは行番号付きで色分けし、長い行はインデントを保って折り返す。編集・全画面・大きさの固定・名前の変更は Markdown と同じ（全画面は本文だけ）。実行はできない |
| PDF | PDF をドロップすると、ページを横 4 枚ずつ並べたキャンバスと、その Portal（サムネイルは 1 ページ目）ができる。ページは固定してあるので、上に付箋やフリーハンドで書き込める。右クリックで「固定を外す」「固定する」 |
| PDF の引用 | ページの上を Alt+ドラッグ（または右クリック →「範囲を選んで引用」のあとドラッグ）で範囲を囲み、「このページの横に引用ノート」か「引用をコピー」を選ぶ。中の文字を引用し、文字がほとんどない範囲（図や表）は切り抜いた画像にする。コピーしたものは、別のキャンバスに貼ると引用ノートになる |
| Markdown の引用 | その場の編集で文字を選び、帯の「引用」→「カードの横に引用ノート」か「引用をコピー」。全画面のエディタでは「引用をコピー」。ファイルが変わっても引用した文字列を探して行番号を付け直し、見つからなければ「位置不明」と出す |
| 引用ノート | 上に出典（資料の名前とページ・行）と引用、下に自分のメモ（ダブルクリックか Enter で書く）。出典の帯を Ctrl（⌘）+クリック、または右クリック →「出典へ」で、PDF のその範囲（しばらく強調する）や、全画面のエディタのその文字へ移る |
| 逆リンク | PDF のページには、引用した範囲が薄い枠で出る。クリックすると引用しているノートの一覧が出て、選ぶとそこへ移る。Markdown カードは右クリック →「引用しているノート」 |
| 外での変更 | SSH などでファイルを書き換えると、カードに反映される。保存していない編集がある場合は、どちらを使うか尋ねる |
| 矢印の編集 | 選ぶと端と真ん中にハンドルが出る。端を動かしてつなぎ直す、真ん中を引っ張って曲げる。ダブルクリックでラベル。色・太さ・矢じりは左端のパレット |
| 削除 | Delete / Backspace |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y） |
| 取り消し | Esc（ドラッグ中なら開始時の状態に戻す） |

画面上部の「ベンチマーク」で、1 万ノードを置いた状態のパン・ズームのフレーム時間を測れる（MAI-14）。
